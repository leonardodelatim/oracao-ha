# Oração Automática para Home Assistant

App (add-on) do Home Assistant que baixa todo dia a oração de um chat do Telegram e envia como nota de voz para grupos e pessoas no WhatsApp.

## Instalar

[![Adicionar repositório ao Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fleonardodelatim%2Foracao-ha)

Ou faça manualmente: **Configurações ▸ Apps ▸ Instalar app ▸ ⋮ ▸ Repositórios**, cole `https://github.com/leonardodelatim/oracao-ha` e adicione. Depois instale **Oração Automática**.

As instruções completas estão na aba **Documentação** do app.

> ⚠️ O envio pelo WhatsApp usa uma conexão não oficial, como o WhatsApp Web, e pode levar ao bloqueio do número.
